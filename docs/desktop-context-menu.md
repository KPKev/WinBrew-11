# Desktop context menu

The source includes modern and classic desktop-background context menus. View supports three icon sizes and visibility, Sort by Name rearranges the shell's virtual shortcuts, Refresh reloads stored desktop shortcuts and positions, and the settings links open the corresponding Wine 11 settings pages. Icon sizes, visibility, and sorted positions persist when preferences are available.

Menu dimensions, typography, icons, separators, and submenu placement follow the supplied Windows 11 reference images. The desktop draws its own approximate acrylic tint and glyphs rather than using Microsoft's native shell, so the result is not pixel-identical across wallpapers or hardware.

The other displayed commands are disabled: this shell does not yet provide Windows desktop-file creation, undo, clipboard paste, a terminal, auto-arrange or grid alignment, or the remaining file-metadata sorts. The classic menu shows the reference screenshot's third-party extension names as disabled visual placeholders; those Windows applications and extensions are not included or detected. This is host-tested source work, not a PS5 deployment or hardware acceptance.
