# Isolated input mode proposal

This host-only state machine is a design experiment, not integrated or install-ready. Start in controller mode. Reserve touchpad click, L3 and R3 from the game at all times; holding all three toggles once. This is distinct from the existing Options+Create close chord, but reserves three normally useful game controls. Pointer mode neutralizes the entire gamepad, uses right stick as mouse, and Cross as left click. Controller mode sends gamepad input and no synthetic pointer or keyboard events. No game-specific or existing profile bindings are supported by this experiment.

The state machine remembers an accepted click, retries a failed release, stays neutral during release retry, and waits for all buttons to be released after a transition. It never injects keys, so it cannot create stuck keys itself. Integration must first release and track all previously accepted synthetic key and mouse bindings, accounting for duplicate bindings and queue rejection; merely replacing the existing event path can strand old inputs. Disconnect, system overlay, queue saturation, teardown, read errors, and rejected release must be handled explicitly. The callback's success means queue acceptance, not delivery. A stopped queue cannot guarantee release.

Integration must neutralize all axes, triggers and buttons (not just `game_buttons`) in pointer mode and during transitions; gate re-entry to controller mode until sticks/triggers are neutral as well as buttons, suppress pointer movement during transitions, clear fractional pointer motion, and avoid conflicts with physical mouse/keyboard events. Chord timing must use validated elapsed monotonic time, not the demonstration's 60 samples; sample batches, disconnect, and overlay interception require careful handling. The chord is not collision-free until its controls are reserved before the Wine sink; this reservation sacrifices game inputs. Provide clear mode feedback and an accessible way to change modes before deployment. The existing Options+Create close logic must remain independently active.

Run `bash research/skyrim/test_input_toggle.sh`. It checks a separate chord, one toggle per hold, no game button output in pointer mode, click delivery and retry, transition gating, and disconnect release. It does not compile the full launcher, test stick gating or delivery through Wine, or establish console or game behavior.
