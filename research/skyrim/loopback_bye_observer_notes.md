# Isolated BYE observer

This source is a separate 120-second variant of the existing loopback observer. After a syntactically matching, unauthenticated HELLO, it accepts only the exact ps5log `BYE seq=<unsigned decimal> reason=<fixed reason>` frame, with checked 64-bit sequence parsing and no trailing characters. It emits only one of `invalid-descriptor`, `invalid-per-game-arguments`, or `per-game-bootstrap`. It does not retain raw input or emit sequence values. A matching sender can be impersonated, and a missing BYE does not distinguish a crash, send failure, filtering, or lost stdout. The bootstrap category does not identify a specific substage.

Host test `bash -lc 'python3 research/skyrim/test_loopback_bye_observer.py'` checks exact documented wire examples, split lines, rejected overflow and malformed frames, injection and nonallowlisted reasons, in addition to the inherited timeout, EOF, byte cap, backpressure, and socket descriptor checks. The test does not execute the native logger or wait the full 120-second production interval. `bash research/skyrim/compile_loopback_bye_observer.sh` compiles the standalone PS5 ELF and prints hashes. No console execution, game file or launcher change, or publisher action was performed.
